# Support Saeium

Saeium is a free Blogger theme. If you find it useful and would like to support its development, you can send a voluntary payment through PayPal.

1. Open [PayPal](https://www.paypal.com/myaccount/transfer/) and choose **Send**.
2. Enter the recipient email **`prasojodwip@gmail.com`**.
3. Check the recipient details shown by PayPal, choose your amount, and review any fees or currency conversion before confirming.

This page provides payment instructions; it is not a PayPal checkout page. No payment is collected by GitHub or the Saeium theme. A direct PayPal button can replace this page when the project owner provides a verified PayPal.Me or hosted payment link for Saeium.
