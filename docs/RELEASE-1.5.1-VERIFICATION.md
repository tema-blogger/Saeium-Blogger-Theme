# Saeium 1.5.1: Layout verification

Date: 2026-11-14. Target: [live Blogger demo](https://saeium.blogspot.com/).

## Change

The Blogger Layout panel now shows **Saeium Blogger Theme · v1.5.1** and nine short, ordered sections from Header & Logo through Footer Credit. The content and sidebar share one panel frame. Sidebar follow text and footer description have their own native HTML/JavaScript gadgets; their original public text remains the default when the gadget content is empty.

## Checks

- XML parsed and passed the Blogger theme validator with the live 1.5.0 XML as its baseline: nine sections, eleven widgets, no missing baseline IDs, and no structural errors.
- All nine original widgets retained their type and every stored `b:widget-setting` value. New widgets are `HTML4` (Follow this blog) and `HTML5` (Footer description).
- The live Layout renderer showed all eleven native widget cards and Edit controls. Both new HTML/JavaScript forms opened with title and content fields; they were closed without saving test content.
- Layout-only recent, saved, and quick-link modules were hidden. The live panel no longer showed the stray list marker between sidebar and footer.
- The live homepage still showed six story cards, one follow module, the existing footer links, and the default footer description. A live article retained its cover, comments, follow link, and footer description.
- No GitHub repository was updated.
